# SoftwareDrones

Dron DJI Tello + visión por computadora para detección de estrés hídrico y plagas en
cultivos, con mapeo del lote y reporte automático en PDF.

Ver `PLANNING.md` para arquitectura completa, estructura del repo y roadmap por sprints.

## Setup rápido

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```
